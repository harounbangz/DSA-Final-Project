# Data Structures and Algorithms Final Project

## Implementation of Classical Data Structures and Algorithms Using Python


## Project Overview

This project demonstrates the implementation of important Data Structures and Algorithms concepts using Python.

The project focuses on solving classical computational problems through practical programming implementations.

The following algorithms are implemented:

- Tower of Hanoi using Recursion
- Binary Tree Traversal Algorithms
- Huffman Coding Algorithm
- Dijkstra Shortest Path Algorithm
- Prim Minimum Spanning Tree Algorithm


---

# Objectives

The main objectives of this project are:

- Understand fundamental data structures.
- Apply algorithms to solve computational problems.
- Implement algorithms using Python.
- Analyse algorithm efficiency.
- Improve problem-solving skills.
